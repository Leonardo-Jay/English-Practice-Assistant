# 本地字幕剧情知识

作品提及检测与聊天异步执行。用户可以打开字幕知识库，确认电影或电视剧的季集，然后导入字幕或复用已有内容。

公开版本包含本地文件导入、归档校验、分集识别、对白清理、场景与剧情总结、缓存复用和知识检索。剧情总结需要用户配置的大模型服务。

字幕保存在 EXE 同级 `data/subtitles`，SQLite 保存元数据和相对路径。导入只复制文件，不修改原始文件。同一季字幕包可以按集延迟总结。

字幕知识仅在已关联并且当前问题需要剧情时注入。导入和总结在后台执行；关闭弹窗不取消任务，取消按钮会终止当前任务。

在线字幕来源是可选私有扩展。公开模块只定义 `sources/types.ts` 中的接口，并注入适配器与会话工厂。公开源码与默认打包不包含任何站点解析器、验证码实现、站点网页样本或默认站点地址。
